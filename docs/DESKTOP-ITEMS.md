# LUMA Desktop Items

The LUMA Desktop surface now discovers immediate visible entries from the current user's Desktop and the shared Public Desktop:

- Folders open inside the LUMA File Manager.
- Windows shortcut files (.lnk) launch through the Windows shell.
- Ordinary files open with their registered Windows default application.
- Hidden and system entries are omitted.
- The mixed item order is persisted locally and supports drag reordering plus keyboard-accessible up/down controls.
- Context actions can open an item or reveal it in File Explorer.

This is still a workspace surface inside the LUMA application, not a replacement for the Windows desktop. It does not modify the source files and does not yet support icon coordinates, drag-out file operations, delete, rename, copy, or move.
